# Aether Homes

Премиум вебсайт барои ширкати сохтмони хонаҳо.

## Хусусиятҳо

- Hero section бо видео
- Каталоги хонаҳо бо филтр
- Портфолио
- Ҳисобкунаки арзиши сохтмон
- Раванди 6-қадамӣ
- About & Contact
- Admin Panel (localStorage)

## Чӣ тавр кушодан

Файлҳои `index.html` ва `admin.html`-ро дар браузер кушоед.

## Технологияҳо

- HTML5 / CSS3 / Vanilla JS
- GSAP (опционалӣ)
- Responsive design
- localStorage барои admin
