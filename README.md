# Aether Homes

Премиум вебсайт барои ширкати сохтмони хонаҳо (Aether Homes).

## 🔗 Live Demo

Пас аз фаъол кардани **GitHub Pages** сайт дар ин ҷо дастрас мешавад:

**https://kayumovyokub708-blip.github.io/aether-homes/**

### Чӣ тавр GitHub Pages-ро фаъол кардан:
1. Ба репозиторий равед: https://github.com/kayumovyokub708-blip/aether-homes
2. **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** / **/(root)** → Save
5. 1–2 дақиқа интизор шавед — силкаи боло кор мекунад.

## Хусусиятҳо

- Hero section бо видео
- Каталоги хонаҳо бо филтр (муосир / классикӣ / минималистӣ)
- Портфолиои хонаҳои сохташуда
- Ҳисобкунаки арзиши сохтмон
- Раванди 6-қадамӣ
- About Us + Contact (телефон, WhatsApp, Telegram, Instagram)
- **Admin Panel** (`admin.html`) — илова / таҳрир / нест кардани лоиҳаҳо (localStorage)

## Технологияҳо

- HTML5 / CSS3 / Vanilla JS
- Responsive (мобил + десктоп)
- Smooth animations & reveal effects
- Premium dark theme + gold accent

## Локалӣ кушодан

Файлҳои `index.html` ва `admin.html`-ро дар браузер кушоед.
